- 회귀 테스트 11개 통과: 계정/scrypt/세션, HTTP 시험/정답 비공개/소유권/로그아웃, 한국어 DOCX, 텍스트 PDF, 학생 OCR 차단, 운영자 스캔 PDF 실제 OCR, 원문 디스크 제외/30분 만료.
- Claude CLI 실제 호출: 기존 로그인 이용, tools 비활성화, JSON schema, 세션 기록 비활성화. API 키 없는 환경에서 실제 문항 생성 성공.
- PDF 실제 AI 통합: 텍스트 PDF → 2문항 생성 → 채점/근거 → 회원가입/저장/조회 → 같은 원문으로 다른 질문 생성 성공. 짧은 자료에서는 요청 2개를 1개로 줄이고 감소 이유를 반환.
