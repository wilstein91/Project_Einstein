# 이해했나? PRD v0.1

대상: 어떤 학문이든 공부하는 학생. 초기 검증은 에이전틱 AI 초심자입니다. 공동 풀이와 공유는 제외합니다.

파일 하나(.docx/.pdf/.md/.txt, 최대 10MiB) 또는 직접 입력한 자료로 4지선다 시험을 만듭니다. 일반 PDF는 암호화되지 않고 텍스트가 추출되어야 합니다. OCR은 운영자에게만 허용하며 인증·엔진 연결 전까지 비활성화합니다.

기본/심화 모두 자료 안에서만 출제합니다. 기본은 핵심 이해, 심화는 비교·관계·적용입니다. 정답 하나와 혼동 가능하지만 명확하게 틀린 오답 세 개를 구성합니다. 말장난은 금지합니다. 문항 수는 자동(3~20) 또는 직접 1~20개이며 자료가 부족하면 줄이고 이유를 표시합니다.

한 문항씩 선택 → 정답 체크 → 정오·한 문단 해설·근거 → 다음 문항 순서로 진행합니다. 최초 답변을 확정합니다. 상단에 현재/전체, 정답 수, 채점 완료 수 기준 정답률을 표시합니다. 정답은 초록색 ‘정답!’, 오답은 빨간색 ‘땡!’입니다.

종료 후 모든 문항·보기·선택 답·정답·해설·근거를 한 페이지 시험지로 표시합니다. 다시 해보기는 동일 자료/설정으로 새 문항을 생성하며 직전 질문을 제외합니다. 새로고침 시 브라우저 임시 상태로 이어갑니다.

V1은 비로그인 시험 기능 검증. V2에는 로컬 이메일/비밀번호 로그인과 시험지·답변·점수 저장/조회를 구현합니다. 원본 파일과 분석 원문은 영구 저장하지 않습니다. 계정 저장은 생성된 문항·해설·근거·답안만 포함합니다.

디자인: 아이보리와 청록, 충분한 여백, 모바일 대응, 시작 화면의 소량 생성 이미지. 시험 화면은 가독성 우선.
